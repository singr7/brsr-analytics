# Launch gates

DEPLOYMENT.md §5 states: **no launch without all three files existing.** Each gate file records a
dated human sign-off. The mechanics live in code; the signature lives with a named person.

A gate file is not a checklist to tick during the launch window — it is evidence that the review
happened. An unsigned gate blocks launch by design. Do not sign on someone's behalf.

| Gate | File | Owner | Status |
|---|---|---|---|
| Legal | `legal.md` | counsel | **unsigned** |
| Editorial | `editorial.md` | editorial owner | **unsigned** |
| UX | `ux.md` | UX owner | **unsigned** |
